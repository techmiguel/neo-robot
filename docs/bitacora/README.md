# Bitácora de módulos

Notas de desarrollo por módulo completado. Un archivo por módulo, nombrado `M<numero>.md`
(ej. `M1.1.md`, `M3.4.md`).

Propósito: capturar decisiones, problemas encontrados y soluciones mientras están frescas,
para que el futuro uno (o un asistente) no tenga que redescubrirlas leyendo diffs.
