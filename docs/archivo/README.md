# Archivo

Notas de las primeras fases del proyecto, guardadas como registro. **No describen el
diseño actual**: por ejemplo, `comandos.txt` supone que el ESP32 llama a las API de
clima y noticias, cuando hoy todo eso vive en el servidor Python.

| Archivo | Contenido |
|---|---|
| `comandos.txt` | Primera especificación de los comandos de voz. |
| `machine_learning_guide.txt` | Guía general de entrenamiento de modelos de voz TinyML, usada al empezar la fase 4. |

El diseño vigente está en el [README](../../README.md), en
[`estrategia-software.md`](../estrategia-software.md) y en el [ROADMAP](../../ROADMAP.md).
